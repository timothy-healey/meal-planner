Receipt body (paper)

  • Background #fbfbf2 (warmer than colors.cream)
  • Padding 22dp horizontal, 22dp top, 130dp bottom (for footer clearance)
  • Centred chain: size 18, weight 800, letterSpacing: 1.8
  • Centred branch underneath: size 11, weight 700, letterSpacing: 1, opacity: 0.75
  • Branch line hidden if empty.
  • Date line: {D MMM YYYY · HH:mm}, size 10, #898970, weight 600, marginTop 6
  • Dashed divider: borderTopWidth: 1, borderStyle: 'dashed', borderColor: #b8b8a0, marginVertical 14

Rows

  • Padding vertical 9dp
  • Name (size 13, weight 700, colors.green)
  • Subtitle (qty · brand · product, size 10, weight 600, #898970)
  • Price (size 13, weight 800, fontVariant: ['tabular-nums'], colors.green)

Footer (sticky)

  • Background #fbfbf2 (continues paper)
